# Legacy Altium projects (outdated)

These Altium Designer projects are kept for reference only. They predate the
3.3 V EMG analog front-end redesign, which is done in KiCad and fabricated
through JLCPCB. Do not build from these files.

| Folder | Was at | Contents |
|---|---|---|
| `emg_headband_flexpcb/` | `emg_headband/headband_flexpcb/` | Headband flex PCB: schematic, layout, BOM, Altium local history and ECO logs (Aug 2025) |
| `pedal_unit_BCI_Pedal/` | `pedal_unit/BCI_Pedal_AltiumProject/` | Empty pedal project stub (project file and constraints only) |

The folders were moved with `git mv`, so `git log --follow` still shows their
full history.
